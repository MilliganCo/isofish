# IsoFish

## О проекте

`IsoFish` — экспериментальный игровой прототип с изометрическим или pseudo-voxel миром, ASCII-рендерингом и мини-игрой про рыбалку. По структуре проект сочетает генерацию мира, управление персонажем, HUD, консольный вывод и отдельные игровые способности.

## Что реализовано

- игровой мир с отдельной логикой в `game_world.py`;
- игрок и набор стартовых способностей;
- ASCII-рендеринг сцены поверх voxel-like представления;
- HUD и консольный слой;
- рыбалка как отдельная мини-игра с кольцевой механикой;
- альтернативная ветка/вариант реализации в подпапке `1/`.

## Стек и структура

- Python
- `pygame`
- основные файлы: `main.py`, `game_world.py`, `player.py`, `abilities.py`, `ascii_render.py`, `console.py`, `hud.py`

## Запуск

```bash
python main.py
```
